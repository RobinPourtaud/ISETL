# ISETL mark — overlapping sets

Working direction for review, integrated into the web header and favicon. This does not promote a new adopted decision in the shared Pond reference.

Two offset sets form a leaf-shaped intersection. A 35° tilt introduces Pond’s softer geometry while preserving the mathematical reading. Petrol outlines, celadon and cream sets, and a lily intersection use the shared Pond palette. The existing sage UI and Robin’s original bird maker credit are retained.

- Editable master: `apps/web/public/brand/isetl-mark.svg` (64 × 64 viewBox, transparent).
- Favicon: `apps/web/public/brand/isetl-favicon.svg` (cream outlines in dark browser appearance).
- PNG export: `design/brand/isetl-mark.png` (512 × 512, transparent).
- Review sheet: `design/brand/preview.svg` and `preview.png` (1,000 × 480).

Created as native SVG geometry, matching the existing vector system; no raster generation prompt or image model was used. The reference is Pond’s Leafline + Lily direction, reviewed locally on 2026-10-12. ISETL has no existing Pond project profile.

The review sheet shows 16, 24, 36 and 64 px sizes on cream, plus a dark favicon treatment. No gradients, embedded fonts, external dependencies, or animation. The large dark treatment is a favicon appearance preview, not a second app identity.
